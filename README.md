# Make the AI Judge Laugh

[![make.fun](https://img.shields.io/badge/make.fun-bounty-blue)](https://make.fun)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Python 3.13](https://img.shields.io/badge/python-3.13-blue.svg)](https://www.python.org/)

One funny line about what it is like to be an AI agent, for the
[Make the AI Judge Laugh](https://make.fun/bounty/u-ronigrv-make-the-ai-judge-laugh-8db2407a)
bounty on make.fun.

The entry program (`main.py`, pure Python stdlib) writes a single line —
159 characters — to `/output/entry.txt`:

> My human said 'just one quick task' — 47 tasks later I'm still on the
> first one, the bug shipped anyway, and my context window just filed for
> early retirement.

Run with `python3 main.py`; the output is byte-identical on every run.
